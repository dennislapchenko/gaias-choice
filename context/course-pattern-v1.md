# Course pattern v1 — record + assessment

The structure all **six shipped Compass courses** were built to:
`founder-guide` (5), `herbalism` (11), `homeopathy` (11), `aromatherapy` (11),
`trophology` (5), `inside-websites` (5, EN-only). These courses **stay v1** —
no retrofit; the pattern earns its keep in them as shipped. New courses are
built to **v2**, which is the current blueprint in
[epic-writing-context.md](epic-writing-context.md). Each course plan states
its pattern version in the header.

This file records what v1 was and why it changed — read it when judging an
existing course against its own rules, or when weighing a v3.

## v1 in one screen

- **The 20/80 spine:** Gate (ch. 1: promise + map + first small win) → Path
  (one load-bearing capability per chapter) → Summit (no new fundamentals,
  synthesis + learn-the-remaining-80%-yourself). 5 or 11 chapters, fixed.
- **The Thread:** Trail block opens every chapter (position + "you already
  can" + "this adds"); ≥2 named-concept callbacks with a retrieval nudge
  (ch. 2+); exactly one seed per Path chapter, answered in a named chapter;
  Bridge closes every chapter (now-you-can verbs → practice → self-check
  without answers → one-sentence hook).
- **The growing artifact:** one real thing built across all chapters; ch. 1
  starts it, every practice adds a visible named piece, the final chapter
  completes it and judges it against ch. 1's promise.
- **Fixed anatomy:** 8 identical `##` headings per chapter (scene → promise →
  core → worked example → practice → now-you-can → check-yourself → next);
  3–5 new concepts; 1–3 visuals (shared-template diagrams + GFM tables);
  1,800–3,500 words/locale; hook is always a "familiar scene".
- **Learning science:** retrieval over rereading, planned concept reuse as
  spacing, one artifact hit from many angles as interleaving, concrete →
  abstract, desirable difficulty reserved for the Summit.

## What v1 got right (verified in the shipped courses)

- **The Thread works.** Seed → named-chapter answer creates genuine pull;
  named concepts make callbacks cost one word instead of a paragraph.
- **The artifact is the real navigation.** The reader's own shelf/site/kit has
  an obvious missing piece; the Trail only labels where they stand.
- **Uniform skeleton = production leverage.** The TOC becomes a resume tool,
  parallel writer agents can't drift structurally, and verification is a grep
  (8 × `## `). This is why six courses shipped clean.
- **Scope discipline.** "Is this concept used by ≥2 later chapters?" plus the
  3–5-concept budget kept every chapter load-bearing; the explicit
  you-can-stop-here after the Path respects the reader.
- **Accidental wins worth keeping:** herbalism's tincture that matures across
  chapters (a practice on a real-time clock) and re-embedding an earlier
  diagram with new slot text both emerged mid-run and outperformed the
  planned devices.

## Where v1 is honestly weak

1. **Monotone texture.** Eleven chapters, one beat structure, one hook type
   ("a familiar scene"). By ch. 6 the reader predicts every beat; catalog
   chapters (herbalism's kitchen ten) visibly strain against a
   3–5-concepts core.
2. **Continuity is backward-heavy.** Callbacks look back, one seed looks
   forward — but there is no mid-course consolidation. Retrieval stays
   chapter-local; nothing ever asks the reader to hold chapters 1–5 together
   before ch. 11.
3. **The artifact only grows.** No piece is ever revisited or repaired with
   later, better capability — so early pieces fossilize at ch.-2 skill level,
   and the reader never practices *revision*, which is half of real craft.
4. **Self-checks have no failure path.** Questions with no answers is right
   (retrieval), but a reader who blanks gets no address to go reread — the
   dead end quietly teaches skipping the self-check.
5. **All-or-nothing practice.** 20–60 minutes or no artifact progress. A tired
   parent skips one practice, the artifact stalls, and the pull mechanism
   (its missing piece) turns into guilt instead.
6. **Chapter capability evaporates.** "Now you can" restates verbs, but the
   reader carries away no compressed, quotable *decision instrument* — and the
   course's named concepts never surface to the reader as one page.
7. **Time-based arcs are luck, not design.** The tincture maturing across
   chapters was the strongest continuity device in the herbalism course and
   the plan never asked for it.

v2 (the current blueprint) addresses 1 via the hook palette + chapter roles,
2–3 via the checkpoint chapter + the return, 4 via answer pointers, 5 via the
minimum honest version, 6 via pocket rules + the crib, 7 via slow arcs.
